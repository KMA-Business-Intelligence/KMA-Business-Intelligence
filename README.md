# KMA Business Intelligence

Sitio de presentación de KMA Business Intelligence: implementación de CRMs
(GoHighLevel, Monday.com, Google Workspace) y sistemas operativos a la
medida (flujo de caja, inventario, dashboards de cuentas).

## Estructura

- `index.html` — página principal
- `mockups/` — ejemplos de sistemas implementados, con negocios ficticios
  - `ferreteria-rodriguez.html` — landing page de negocio local
  - `restobar-canaima.html` — dashboard de flujo de caja (conectado a Supabase)
  - `grupo-servipro.html` — CRM tipo pipeline de ventas

## Despliegue

Publicado en Netlify, conectado a este repositorio. Cada push a `main`
republica el sitio automáticamente.
